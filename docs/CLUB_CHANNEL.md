# クラブチャンネル管理システム

## 📖 概要

クラブ（共通の興味でゆるく集まる常設の趣味部屋）のチャンネルとロールを、1つのコマンドで作って管理する機能です。チャンネルとロールは**番号**（`c001`など）で結びつきます。

### 主な機能

- **チャンネルとロールの一括作成**: チャンネル `c001-ラーメン` とロール `c001-ラーメン` を同時に作成
- **どこからでも作成**: 承認不要。どのチャンネル・スレッドからでも実行可能
- **メンバー管理**: 作成時または後からメンバーをロールに追加可能。作成した本人は自動で参加者になる
- **ロールの並び**: 作成したロールをクラブのロールの一番下に置く（event/projectのロールより上）
- **上限チェック**: カテゴリ・サーバーのチャンネル数やロール数が上限なら作成しない
- **記録**: 作成とメンバー追加をクラブのチャンネル内に残す（[ARCHITECTURE.md](./ARCHITECTURE.md#記録の出し先)）

## 💡 使い方

### クラブチャンネルの作成

```
/create_club_channel channel_name:ラーメン members:@user1 @user2
```

**実行結果:**
- チャンネル: `c005-ラーメン`（clubsカテゴリ内。番号は使われている最大の番号＋1）
- ロール: `c005-ラーメン`（メンション可能。クラブのロールの一番下に置く）
- 作成した本人、@user1、@user2 にロールを付与

クラブは常設なので、メンションしたときに何のクラブか分かるよう、ロール名は番号＋名前にしています（event/projectのロールは番号だけ）。

### ロールへのメンバー追加

```
/add_club_role_member members:@user3 @user4
/add_club_role_member members:@user3 role_name:@c005-ラーメン
```

`role_name`を省略すると、実行したチャンネル（スレッドなら親チャンネル）と同じ番号のロールが対象になります。

## 🔧 実装詳細

### チャンネル作成フロー

```mermaid
sequenceDiagram
    participant User
    participant Bot
    participant Discord

    User->>Bot: /create_club_channel
    Bot->>Bot: defer（本人だけに見える）
    Note over Bot: ここから作成用のLock内
    Bot->>Bot: 上限チェック
    Bot->>Bot: 番号を採番（clubsカテゴリの最大＋1）
    Bot->>Discord: チャンネル作成
    Bot->>Discord: ロール作成（失敗したらチャンネルを削除）
    Bot->>Discord: ロールをクラブのロールの一番下へ移動
    Note over Bot: Lockを解放
    Bot->>Discord: 本人と指定メンバーにロール付与
    Bot->>User: 結果（本人にだけ表示）
    Bot->>Discord: チャンネル内に記録
```

### 番号での紐づけ

チャンネルとロールは、名前の先頭の番号（`c005-`）で結びつけます。名前の部分はDiscordの正規化（小文字化、空白をハイフンに、など）でずれることがありますが、番号はずれません。

`/add_club_role_member`は、次をすべて満たすロールだけを操作します。

1. ロール名が `cNNN-` で始まる
2. 同じ番号のチャンネルがclubsカテゴリにある
3. 管理者ロールなどの重要なロールではない（`validate_role_safety`）

番号で結びつけるため、既存の権限つきロール（例: `運営`）と同じ名前のクラブを作っても、そのロールを操作できるようにはなりません。同じ名前のクラブも、番号で区別できるので作成できます。

### 番号の採番

clubsカテゴリにあるチャンネルのうち、`cNNN-` で始まるものの最大の番号に1を足します（`numbering.py`の`next_number`）。欠番は埋めません。clubにはまだアーカイブがないため、clubsカテゴリだけを見ます。

### ロールの置き場所

新しく作ったロールはDiscordの仕様で一番下（@everyoneのすぐ上）に作られるため、作成後に動かします（`role_order.py`の`target_role_position`）。

- 同じ種類のロールがあれば、その一番下に置く
- なければ、下の種類（club＞event＞projectの順）のロールの一番上のすぐ上に置く
- botは自分のロールより上には動かせない。動かせなくても作成は成功扱いにし、warningを出す

## 🆚 イベントチャンネルとの比較

| 機能 | イベントチャンネル | クラブチャンネル |
|------|------------------|----------------|
| **チャンネル名** | `e001-ハッカソン` | `c001-ラーメン` |
| **ロール名** | `e001`（番号のみ） | `c001-ラーメン`（番号＋名前） |
| **採番の範囲** | イベントカテゴリとアーカイブカテゴリ | clubsカテゴリ |
| **アーカイブ・復元** | ✅ | ❌（#16で対応予定） |

## 🐛 トラブルシューティング

### Q: ロールにメンバーを追加できない

**原因:**
1. ロール名が `cNNN-` で始まっていない、または同じ番号のチャンネルがclubsカテゴリにない
2. 管理者ロールなど重要なロールを操作しようとしている

**解決策:**
- 番号のついていない古いクラブは、チャンネル名とロール名を `cNNN-名前` に手で揃える
